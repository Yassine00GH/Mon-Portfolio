# Yassine Ghorbel — Portfolio

Portfolio professionnel Angular + TypeScript + Tailwind CSS.

## Installation
```bash
npm install
npm start
```
Puis ouvrir http://localhost:4200

## Build production
```bash
npm run build
```

## Personnalisation
- Contenu principal : `src/app.component.html`
- Données projets/compétences : `src/main.ts`
- Design : `src/styles.css`
- Déposer le CV final dans `public/` puis ajouter un lien dans le bouton CV si nécessaire.
